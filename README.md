# How archival eclipse timing can produce period change: three mechanisms quantified on 26 short-period binaries

Code, per-target records and manuscript source for the paper of the same title (R. Walitte, submitted to A&A).
This repository is the archive named in the paper's *Data availability* section: every number in the paper is
produced by the scripts here from the records here, and the tables, figures and TeX are regenerated at every run.

## Layout

```
src/                       the scripts named in the paper (Sect. 8), plus the modules they import
data/orquestra/oc_lote/    per-target timing records oc__<TIC>.json (88: 26 measured, 62 stopped at a guard)
                           and the measurement tables of Sect. 5 (*.parquet, caso_232634196.json, previsao_232634196.json)
data/orquestra/            alvos_oc_88.parquet (the 88 targets), the control target's expectation and record
data/results/              vies_cache_288.parquet (MAST sector census of Sect. 2) and the control target's inputs
reports/dpdt_note.md       the manuscript source (Tables 3-5 are inserted into it by tabela_nota.py)
reports/tabelas_nota.md    the generated tables, as markdown
reports/epocas_26.csv      machine-readable table of the 145 epochs entering Table 3 (for the CDS)
reports/figures/           the five figures (PNG), generated by figuras_nota.py
paper/                     dpdt_note.tex (generated), dpdt_note_v1.tex (preamble, author block, table/figure
                           environments and bibliography that the converter reuses), aa.cls, aa.bst, figures/, PDF
```

## Regenerating the paper from the records

```
python src/tabela_nota.py --inserir     # Tables 3-5 and tabela_26.parquet from the per-target records
python src/figuras_nota.py              # the five figures
python src/epocas_cds_26.py             # reports/epocas_26.csv
python src/md_para_tex.py               # paper/dpdt_note.tex from reports/dpdt_note.md
cd paper && pdflatex dpdt_note && pdflatex dpdt_note && pdflatex dpdt_note
```

All of these are deterministic reads of the stored records: run in a fresh copy of this repository they reproduce
`reports/dpdt_note.md`, `reports/tabelas_nota.md`, `reports/epocas_26.csv`, `paper/dpdt_note.tex`,
`tabela_26.parquet` and the figures byte for byte (checked before the first commit).

## The measurement scripts of Sect. 5

Each script carries, in its module docstring, the expectation that was written and committed before it was run,
and the result recorded afterwards; the paper's Appendix D lists the readings that were withdrawn between versions.
The scripts read the per-target records and the tables in `data/orquestra/oc_lote/` and write their own table there:

| script | section | writes |
|---|---|---|
| `qual_barra_26.py` | 5.2.2 | `qual_barra_26` (leverage-corrected residual decomposition by data set) |
| `nulo_barras_reestimadas_26.py` | 5.2.3 | `nulo_barras_reestimadas_26`, `nulo_condicionado_26` (null of the estimator with bars re-estimated) |
| `vies_alavanca_26.py` | 5.2.2 | `vies_alavanca_26` (leverage bias of the estimator with known bars) |
| `estrutura_swasp_26.py` | 5.2.4 | `estrutura_swasp_26*` (injection of the declared orbit population) |
| `completude_secular_26.py` (`--resumo`, `--fator`) | 5.2.5, 5.2.3 | `completude_secular_26*` (completeness and self-suppression for a secular term) |
| `gls_vies_26.py` | 3.4 | `gls_vies_26` (chain bias as a correlated block) |
| `secundarios_26.py` | 5.3.1 | `secundarios_26`, `secundarios_26_setores` |
| `reinflar_tess_26.py` (`--resumo`) | 5.2.1, 5.3.2 | `reinflar_tess_26` (TESS bars at the between-sector scale) |
| `epsilon_26.py`, `v527_ltte.py` | 5.4 | `epsilon_26`, `v527_ltte_injetado` |
| `literatura_26.py`, `comparar_brno_26.py` | 5.5 | `literatura_26`, `minimos_brno_26`, `comparacao_brno_26`, `sobreposicao_brno_26` (network: SIMBAD, VizieR, VarAstro) |
| `caso_232634196.py`, `previsao_232634196.py` | 5.5 | `caso_232634196.json`, `previsao_232634196.json` |
| `blending_26.py` | 3.1 | `blending_crowdsap_26`, `blending_gaia_26` (needs the cached SPOC FITS and VizieR) |
| `vies_cache_288.py` | 2 | `data/results/vies_cache_288.parquet` (network: MAST) |
| `reinflar_swasp_26.py`, `reinflar_conjunto_26.py` | Appendix D | kept for the record of the withdrawn corrections |

The Monte Carlo scripts are seeded; rerunning them reproduces the stored tables up to the order of floating-point
summation.

## The timing chain

`cadeia_oc.py`, `oc_lote.py`, `superwasp.py` and `epocas_142874476.py` are the chain that produced the per-target
records (Sect. 3). Rerunning it needs what is **not** in this repository: the SPOC 2-min light curves from MAST
(the per-sector manifests and the FITS cache), the SuperWASP light curves from the CERIT-SC archive, and the
catalogue query for the 88 targets. The records it produced are here; the control target's expectation and record
(`data/orquestra/*142874476*`, Appendix B) are the reference against which every change to the chain was checked.

## Environment

Python 3.12; numpy 2.5, pandas 2.3, scipy 1.18, astropy 8.0, astroquery 0.4.11, matplotlib 3.11, pyarrow 25
(`requirements.txt`). The TeX compiles with the A&A class shipped in `paper/` (pdflatex, three passes).
